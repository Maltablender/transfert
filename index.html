On t'a envoyé un dossier

Trois gestes sur un PC Windows : le téléchargement démarre tout seul.

  1. 1

    Copie la commande de réception

  2. 2

    Appuie sur ⊞ Windows + R, puis Ctrl + V et Entrée

    Une fenêtre noire s'ouvre. La première fois, elle installe le module de transfert en quelques secondes.

  3. 3

    C'est parti : laisse la fenêtre ouverte

    Le téléchargement démarre tout seul dans ton dossier Téléchargements. Laisse la fenêtre noire ouverte jusqu'au message « TERMINÉ » : le dossier s'ouvre alors tout seul. Si Windows demande une autorisation réseau, clique « Autoriser ».

Si ça coupe : recommence les étapes 1 et 2. Le téléchargement reprend là où il s'était arrêté.
